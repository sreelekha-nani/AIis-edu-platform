# ALIS - Adaptive Learning Intelligence System

## Project Overview
ALIS (Adaptive Learning Intelligence System) is an AI-powered educational platform that personalizes learning experiences for students through adaptive recommendations, analytics, assessments, and role-based dashboards.

## Problem Statement
Traditional education follows a one-size-fits-all approach that does not adapt to individual learning speeds, strengths, and weaknesses. ALIS addresses this challenge by providing personalized learning pathways and intelligent recommendations.

## Features
- Student Dashboard
- Teacher Dashboard
- Parent Dashboard
- Admin Dashboard
- Adaptive Learning Recommendations
- Course Management
- Assessments & Assignments
- Live Classes
- Learning Analytics
- Progress Tracking

## Tech Stack
- React
- TypeScript
- Node.js
- Express.js
- PostgreSQL
- Replit

## Setup Instructions

```bash
git clone https://github.com/sreelekha-nani/AIis-edu-platform.git
cd AIis-edu-platform
npm install
npm run dev
```
